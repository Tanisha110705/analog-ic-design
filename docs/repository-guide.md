# Repository Guide

Every image under `device-characterization/`, `current-mirrors/` and `amplifiers/` is a crop of a genuine Cadence screenshot from the course reports. Crops keep only the schematic canvas or plot window. Title bars, file-browser panes, paths, server names and user IDs were removed, and pixels inside the crop were not altered. The crop boxes are recorded in [`tools/crop_evidence.py`](../tools/crop_evidence.py).

Everything under `assets/` is a **conceptual diagram** generated by [`tools/make_diagrams.py`](../tools/make_diagrams.py). Those are drawings, not simulation output.

```
analog-ic-design/
├── README.md
├── LICENSE
├── .gitignore
├── assets/                      conceptual SVG diagrams (generated)
├── device-characterization/
│   ├── pmos/                    PMOS testbench + 11 characteristic plots
│   └── nmos-gm-id/              NMOS gm/Id lookup sweeps (CS and mirror designs)
├── current-mirrors/
│   ├── simple/                  schematics (100 µA, 500 µA) + Iout–Vout
│   └── cascode/                 schematic (100 µA) + Iout–Vout
├── amplifiers/
│   ├── common-source/           schematic, AC/DC plot, Spectre pz log
│   ├── cascode/                 sizing testbench, schematic, gm/Id sweeps, AC response
│   └── active-load/             NMOS/PMOS sizing testbenches and sweeps
├── docs/                        design write-ups, results, audit
└── tools/                       diagram generator, evidence crop record
```

There are no `simulations/` or `results/` folders. No netlists, ADE states or raw simulation data survive, and results are tabulated in [results.md](results.md).
